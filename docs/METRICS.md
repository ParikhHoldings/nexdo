# Metrics

## Product
- repo/build/deploy verification completeness
- environment readiness across Supabase, OpenAI, Stripe, and app origin
- MVP scope clarity
- number of active bounded execution tasks defined
- successful task capture -> parse -> save completion rate
- daily briefing usefulness and generation success rate
- agent execution success rate for research, draft, and prep tasks
- MCP/API tool success rate and action schema correctness

## Growth
- waitlist or interest capture volume
- qualified user conversations or signals
- landing page conversion once active
- activation rate from signup to first structured task
- import completion rate for users migrating from another task tool

## Business
- path-to-revenue clarity
- time from concept to verified MVP execution
- first monetization milestone readiness
- free-to-paid upgrade intent once quotas are encountered
- Stripe test-mode checkout/portal/webhook verification status

## Quality
- differentiation clarity vs generic task managers
- execution velocity on real product tasks
- public-copy accuracy against verified product behavior
- build/lint/deploy health
- typecheck and Playwright smoke-test health
- dependency vulnerability count and remediation status
- RLS, quota, rate-limit, and API-key security confidence
